Strategy
전략 개요
떨사오팔은 가격 하락 후 반등 신호를 확인하고 진입하는 전략입니다.
📉

RSI 과매도 탐지

최근 N개 캔들 내 RSI가 과매도 구간(RSI ≤ 30~35)에 진입한 이력을 탐지합니다. 단순 임계값 돌파가 아닌, 반등 시작 시그널을 확인합니다.

📊

EMA 크로스 확인

가격이 단기 EMA(EMA 10) 위로 복귀했는지 확인합니다. 장기 추세는 EMA 50으로 판단하여 하락장 진입을 필터링합니다.

🎯

다중 출구 전략

목표 수익률 도달 시 익절, RSI 과매수 시 추가 상승 제한 → 익절. 진입 후 trailing stop으로 수익을 보호합니다.

🛑

추적 손절

진입 후 최고가 대비 일정 수준(1~2.5%) 하락 시 자동 매도. 고정 손절 대비 더 유연한 리스크 관리를 제공합니다.

⏱️

쿨다운 시스템

손절 후 3캔들 동안 재진입을 보류합니다. 연속 손절을 방지하고 시장 안정을 기다립니다.

🔔

텔레그램 알림

매수/매도 신호 발생 시 텔레그램으로 실시간 알림을 발송합니다. 밤 시간대엔 거래소 예약주문을 권장합니다.

How It Works
동작 흐름
4시간마다 cron으로 실행되어 코인별 상태를 점검합니다.
1

시세 수집

Binance에서 1h OHLCV 데이터를 조회합니다

2

지표 계산

RSI(14), EMA(10), EMA(50)를 계산합니다

3

조건 판단

매수/매도 조건을 순차적으로 검사합니다

4

신호 발송

조건 충족 시 텔레그램으로 알림을 보냅니다

Parameters

Features
시스템 특징
🤖

알림 전용

봇은 자산을 만지지 않습니다. 매수/매도 신호만 발송하며, 실제 주문은 사용자가 직접 실행합니다.

🌙

예약주문 지원

밤 시간대엔 거래소 예약주문(지정가 + OCO)으로 대응할 수 있도록 안내합니다.

📈

레버리지 계산

2배 레버리지 기준 증거금 수익률을 함께 표시하여 의사결정을 돕습니다.

🔄

크론 호환

1회 실행 모드를 지원하여 cron으로 정기 점검을 자동화할 수 있습니다.
